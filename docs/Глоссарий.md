# Глоссарий метрик

| Метрика | Определение и ограничение |
| --- | --- |
| SKU / Артикул WB | Карточка товара; строковый ключ. Месяц + SKU уникальны. |
| Сумма выкупов / выручка | Выкупили на сумму, ₽. До комиссий, налогов, логистики и прочих расходов. |
| Сумма заказов | Заказали на сумму, ₽; не равна выкупам или прибыли. |
| Заказы | Заказали, шт: число единиц, не число уникальных заказов или покупателей. |
| Выкупы | Выкупили, шт; не используется как числитель конверсии заказа. |
| Конверсия | Заказанные единицы / переходы. Портфель: отношение сумм; при нулевом трафике недоступна. |
| Доля выкупов | Выкупы SKU / сумма выкупов апреля. |
| ABC | A покрывает первые 80%, B следующие 15%, C остаток; пересекающая порог карточка в предыдущей группе. |
| XZ | Рабочая матрица уровня заказов и заказов/остатка. Не XYZ по вариации. |
| Группа X | Заказы не ниже медианы положительных заказов апреля: 271.5 шт. Z - ниже. |
| Оборот, приближение | Заказы месяца / срез остатка; быстрый ≥1. Не стандартный оборот по среднему запасу. |
| Остаток | WB + МП, шт; дата среза требует подтверждения. Не суммируется во времени. |
| Покрытие запасом | Остаток / средние заказы в день апреля; при нулевых заказах недоступно. |
| MA2 | Среднее заказов двух последних месячных файлов; на май округляется вверх. |
| Наивный прогноз | Заказы будущего месяца равны последнему известному месяцу. |
| WAPE | Σ|факт − прогноз| / Σфакт; общий WAPE - отношение общих сумм, не среднее процентов. |
| Целевой запас | MA2 × 1,20 с округлением вверх. Буфер 20% - допущение. |
| Пополнение | MAX(целевой запас − остаток, 0), до входящих поставок и резервов. |
| Избыток | MAX(остаток − целевой запас, 0), условный сигнал к снижению закупки. |
| Низкая конверсия | ≥1000 переходов и конверсия ниже половины портфельной. Не отраслевой норматив. |
| Маркетинговый кандидат | Рейтинг карточки ≥9, доля выкупов <0,1%, ≥1000 переходов, товар не удалён. |
| Рейтинг карточки | Поле источника с наблюдаемой шкалой до 10; не рейтинг отзывов. |
| Backtest | Исторический прогноз с использованием только информации, доступной до тестового месяца. |
